# collecta-instagram

Calendario de publicaciones de Collecta y publicador automático para Instagram.

1. Edita `schedule.json` (o pídele a Claude Code que lo haga).
2. Una publicación sale sola cuando su `status` es `approved` y llega su hora (`when`).
3. Ver `CLAUDE.md` para reglas y tareas.

Configuración única: ver la guía «Instagram automático: guía para conectar y publicar».
